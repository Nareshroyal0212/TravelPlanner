🌍TravelPlanner
Your smart travel companion for discovering, planning, and managing trips

React • Vite • Spring Boot • Java • MySQL

✨ Overview

TravelPlanner is a full-stack travel management application designed to help users discover destinations, explore hotels, plan trips, manage bookings, organize itineraries, set budgets, and track travel expenses in one place.

It combines a modern React + Vite frontend, Spring Boot backend, and MySQL database to provide a complete travel planning experience.

🚀 Features

🎫 Booking Management — Manage hotel and travel bookings

💳 Expense Tracking — Record and monitor travel expenses

📱 Responsive Interface — Designed for a smooth experience across different screen sizes

🧰 Tech Stack
Frontend

React.js
A component-based JavaScript library used to build the user interface.

Vite
A fast modern development and build tool for the React application.

JavaScript
Used for application logic and interactive functionality.

CSS3
Used to create the application's visual design and responsive layouts.

React Router
Used for navigation between application pages.

Backend

Java
Primary programming language used for backend development.

Spring Boot
Used to build the REST APIs and backend services.

Spring Data JPA
Used for database interaction and persistence.

Maven
Used for dependency management and building the Spring Boot application.

Database

MySQL
Relational database used to store users, destinations, hotels, bookings, budgets, expenses, favorites, and itineraries.
